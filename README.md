# 电商智能导购系统

基于 **FastAPI + LangGraph + RAG** 的电商智能导购 Agent，接入现有商城，支持预算选品、规则咨询、多轮对话与用户确认后的加购。

项目重点：**商品数据实时查询，规则回答附带来源，加购操作由用户明确确认。**

## 演示

**[查看 H5 演示视频（4 分 44 秒）](output/day10/yshop-agent-demo.mp4)**

演示包含商品查询、预算调整、商品指代、规则来源、确认卡准备、刷新恢复和取消。录屏没有执行新的真实加购。

## 主要功能

- **预算选品：** 按具体 SKU 的价格与库存筛选商品，展示可购规格。
- **规则咨询：** 本地中文 RAG 检索演示规则，展示原文来源，依据不足时明确说明。
- **多轮对话：** 接续预算调整、“第一个”等商品指代与规则插问。
- **确认加购：** 生成确认卡，确认前复核价格库存；变价后重新确认。
- **状态恢复：** 持久化会话与动作，防止同一动作重复提交；结果未知时不自动重试写入。
- **H5 交互：** 商品卡、规格选择、规则来源和确认卡，配合 SSE 展示处理状态及结果。

## 技术栈

- **Agent：** Python、FastAPI、LangGraph、Pydantic、httpx
- **检索与存储：** BGE 中文向量模型、Chroma、SQLite
- **商城接入：** Spring Boot、MyBatis-Plus、MySQL、Redis、uni-app H5

## 项目说明

本次新增 Agent 服务、Java 商品查询扩展及 H5 导购交互，复用既有商城的登录、商品和购物车业务。

项目仅用于源码与本地演示展示，不提供公开在线服务；规则为演示资料，未接入自动下单、结算或支付，也未验证生产并发能力。运行需自行准备完整商城环境、数据、登录与模型配置。
