## 修订原因

原版的 `product-baidaiya500` 与 `multi-changing-keyword` 使用“百代亚”并要求非空结果，而真实商城目录中的商品34名为“柏黛雅全套化妆刷套装眼影腮红修容刷子便携彩妆化妆工具官方正品”。当时留档的四次真实只读查询证实：原词在500元预算和无预算时均为空，正确名称在两种条件下均有在售且有库存的商品。

v2只将上述两个步骤的用户消息与预期查询关键词中的“百代亚”改为“柏黛雅”，合计四处字符串替换。保留相同用例ID、50个场景、30条真实场景、20条确定性场景、42个真实步骤，以及全部预算、非空、工具和身份边界断言；没有修改商品目录、应用查询逻辑或判分要求。

## 运行

在项目的 `yshop-agent` 目录执行，每次更换尚不存在的报告文件名，确认8019空闲：

```powershell
$env:LLM_PROXY_URL = 'http://127.0.0.1:7892'
& '.\.venv\Scripts\python.exe' -B -X utf8 -W error -m scripts.eval_day9 --suite day9-v2 --report '.tmp/day9-v2-manual-new.json' --port 8019
```

省略`--suite`时仍运行`day9-v1`；显式选择`day9-v2`才运行新版。报告记录版本标识、清单路径、SHA256和运行前后指纹核验。只有同一完整批次的50个场景均通过、确定性网络门禁与真实模型观测均有效时，命令才返回0。
