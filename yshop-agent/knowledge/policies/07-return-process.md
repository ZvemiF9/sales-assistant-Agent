# 退货流程演示规则

## 申请与寄回材料

演示规则：本演示退货流程为：先通过商城已有客服入口说明订单号、退货原因及商品状态；需要时提供验货照片；获得客服确认及寄回地址后，再按要求寄回商品和配件，并保留物流单号。

演示规则：不要根据外包装上的发件地址自行寄回，寄回地址应由客服确认。购物助手只解释流程，不替用户提交售后申请或创建退款单。是否受理以及实际处理进度，以商城已有售后页面和客服回复为准。
