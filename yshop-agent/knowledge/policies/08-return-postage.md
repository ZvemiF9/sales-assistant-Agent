# 退货运费演示规则

## 售后寄回运费

演示规则：本演示无理由退货的寄回运费由买家承担；经客服确认属于商品质量问题、错发或缺件的，合理寄回运费由商家承担。请在寄回前确认原因、寄回方式和费用处理方式。

演示规则：本资料没有运费补偿上限、运费险额度或指定承运商的具体说明，助手不能自行给出赔付金额。未经确认的到付包裹是否接收需询问客服。以上是演示售后约定，不代表真实商城承诺。
