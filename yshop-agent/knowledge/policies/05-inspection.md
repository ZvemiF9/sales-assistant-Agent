# 签收验货演示规则

## 验货与异常签收

演示规则：收到包裹时，请先检查外包装是否破损、商品数量是否齐全、商品外观是否异常。发现破损、缺件或错发时，建议拍摄外包装、快递面单和商品照片留作售后说明，并尽快通过商城已有客服入口反馈。

演示规则：验货出现异常时可与配送人员沟通，并由客服结合证据确认处理方式。签收本身不表示放弃正常售后申请；本资料不承诺对任何异常自动赔付，也不执行退货或退款操作。
