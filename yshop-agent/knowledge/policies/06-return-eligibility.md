# 退货条件演示规则

## 七天退货条件

演示规则：本演示普通商品支持签收后 7 天内申请无理由退货，前提是商品完好、配件齐全，且不影响二次销售。拆封或使用后是否仍符合条件需客服核实；质量问题、错发或缺件按异常售后处理，不应直接套用无理由退货条件。

演示规则：定制商品、生鲜易腐商品和商品页明确注明不适用无理由退货的商品不参加此演示约定。最终以商品页及商城客服确认结果为准。这是测试规则，不能视作实际法定权益的完整说明。
