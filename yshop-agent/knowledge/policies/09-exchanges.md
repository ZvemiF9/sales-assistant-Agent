# 换货演示规则

## 换货条件与库存

演示规则：本演示换货需商品符合售后条件，并且目标规格有可用库存。申请时通过商城已有客服入口提供订单号、希望更换的颜色或尺码及原因，由客服确认是否受理、差价和寄回安排。

演示规则：换货不保证保留库存，缺货时需与客服协商其他方案。本资料没有承诺跨商品换货、无条件补差价或免运费。助手可以解释换货条件，但不会直接修改订单、扣款或执行换货。
