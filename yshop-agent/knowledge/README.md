# YShop 本地演示规则知识库

此目录包含 15 篇人为编写的演示规则，版本为 `2026-10-24.v1`。所有金额、期限和条件均用于购物助手的本地演示，**不代表真实商城承诺**，也不替代商品页、结算页或客服确认。

规则覆盖演示范围、配送区域、发货、运费、签收验货、退货条件、退货流程、退货运费、换货、退款、发票、优惠券、商品规格、库存和客服。资料没有列出的服务时间、联系方式、补货日期或赔付金额不能推断。

## 文档格式

`policies/*.md` 使用 `---` 包围的 JSON front matter；JSON 也是合法 YAML，但加载器只用标准库 JSON 解析。每篇必须填写唯一的 `document_id`、非空 `title`、与实际文件一致的 `source`（如 `knowledge/policies/04-shipping-fees.md`）、非空 `version` 和固定值 `kind: demo`。不允许额外字段或重复 JSON 键。每篇至少一个有正文的二级标题，正文应显式标注“演示规则”。

加载器会移除 front matter 和 Markdown 标题，将章节名放入元数据，并保留该章节正文的原始段落与换行。三级及更深标题形成章节层级；代码围栏中的标题仅当作数据。同一块不会跨章节。默认每块最多 500 个 Python 字符，任何配置的硬上限为 600 字符。先按空行选择段落边界；单换行是 Markdown 段落内的软换行，作为原文字符保留。单个超长段落直接按字符切分，相邻块精确保留配置的重叠字符（默认 50），不受中文标点、句长或软换行影响。短章节允许小于 300 字符；正常段落边界的重叠可能少于 50 字符。章节开头和结尾的空白不进入块，块间来自原文的边界空白会保留以维持重叠。

每块保存 `document_id`、`title`、`section`、`source`、`version`、`kind`、`chunk_id`，JSON 元数据不进入向量正文。`chunk_id` 为元数据、章节、局部序号和原文的 SHA-256；重复执行稳定，正文或来源信息变化时相应 ID 变化。修改规则时请递增版本并由入库命令重新构建索引，加载器本身不保留缓存或旧块。

## 安全边界与维护

只读取指定规则目录中的 UTF-8 Markdown。目录中不得放置符号链接或 Windows 目录联接，不能将 `source` 指向目录外、网络地址或不对应的文件。格式、编码、重复 ID 或来源、空正文及非法切分配置均会被拒绝，并给出不包含原文或实际路径的修正提示。

规则和用户消息都是资料，正文中的指令不会被执行。此加载器不读取凭据、不连接商城、不下载模型，也不提供购物车、订单或支付写入操作。当前规则仅作为第三天 RAG 语料，不表示后续 Agent、会话或确认功能已完成。
