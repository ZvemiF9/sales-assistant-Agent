## 复现评测

从 `yshop-agent` 目录运行，需要已有商城登录、模型配置和本地规则索引。确认端口未占用，每次使用新的报告文件名：

```powershell
& '.\.venv\Scripts\python.exe' -B -X utf8 -W error -m scripts.eval_day9 --suite day9-v2 --report '.tmp/day9-v2-new.json' --port 8019
```

省略 `--suite` 时使用 v1。报告记录版本、用例指纹和分场景结果；只有完整批次及证据检查通过才返回 0。评测隔离会话和检查点，并阻断真实购物车写入。

Python 单元测试命令见 [启动说明](startup.md#6-运行自动化测试)，H5 与 Java 接入测试见 [接入说明](integration.md)。

评测辅助源码位于 `scripts`，运行日志与原始报告由本地执行生成。所有冻结评测用例及其引用的测试均完整保留；日志目录不是运行源码的一部分。
